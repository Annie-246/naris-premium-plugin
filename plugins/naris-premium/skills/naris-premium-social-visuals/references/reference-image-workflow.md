# Turning references into a Naris Premium concept

Use this workflow only when the user provides one or more reference images.

## 1. Assign a role to every image

Identify whether each image is product truth, style reference, content reference, edit target, or brand asset. Do not assume that every visible object must appear in the result.

## 2. Deconstruct useful qualities

Read each style reference through these dimensions:

- composition and focal hierarchy;
- camera angle and crop;
- lighting direction, softness, and contrast;
- color relationships;
- materials and textures;
- typography character and placement;
- depth, negative space, and graphic rhythm;
- product scale and interaction with props or people.

Describe the transferable qualities abstractly. Avoid copying a distinctive campaign layout, illustration, character, artwork, or branded device.

## 3. Make a keep / translate / discard map

- **Keep:** details the user explicitly requests, such as a low camera angle, hand pose, glass pedestal, diagonal product arrangement, or spacious headline zone.
- **Translate:** useful qualities adapted into the Naris system, such as changing a bright reference palette to warm ivory and cocoa, simplifying dense decoration, or converting flashy lighting into controlled cosmetic light.
- **Discard:** the reference brand, products, logo, wording, claims, prices, badges, watermarks, people not authorized as content references, and any element unrelated to the brief.

When references conflict, prioritize in this order: user's explicit instructions, product truth, requested must-keep details, Naris brand rules, then optional style qualities.

## 4. Synthesize one new concept

Do not average every reference or build a checklist collage. Choose the strongest compatible qualities and describe one coherent composition. The result should be recognizably Naris Premium even when the reference belongs to another visual world.

## 5. Write attachment roles into the generation prompt

State clearly which image controls product identity, which is only style inspiration, which elements must be retained, and which brands/text/objects must not transfer. Attach the approved Naris social logo separately and instruct the model to preserve it exactly.

## 6. Verify after generation

Compare the output against both the brief and references:

- Are the requested reference details actually present?
- Was anything copied that the user did not ask to retain?
- Did the product or reference brand leak into the wrong role?
- Did Naris palette, restraint, typography character, and logo rules remain dominant?

Regenerate or edit when a must-keep detail is absent, a discarded element leaks through, or the result resembles the reference more than the Naris brand.
